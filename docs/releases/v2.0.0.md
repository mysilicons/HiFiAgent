# HiFi Agent v2.0.0

Released locally on 2026-07-29.

V2 adds auditable optimization for at most three rounds: typed proposals, deterministic safety
approval, immutable attempts, actual-argv contracts, protected multi-metric comparison, explicit
stop states, and V2 reports.

## Acceptance evidence

- Genuine Candida baseline and one repaired single-variable candidate completed.
- Candidate parameter contract: `PASS`; actual argv is traceable from report to execution manifest.
- Genuine Candida terminal outcome: `STOP_PLATEAU`; no improvement claim.
- Genuine Candida and Drosophila full FASTQ SHA-256/size/header checks passed.
- Five production-comparator safety scenarios passed.
- A/B/C/D ablation was generated; live DeepSeek returned zero candidates and did not change the
  deterministic outcome.
- Three-round fixture completed all three rounds and enforced `STOP_MAX_ROUNDS`.
- Data-free installed-package demo passed 5/5 scenarios.

## Boundaries

- Drosophila was used for genuine full-input integrity and scale audit, not an assembly result.
- Safety scenarios and the three-round proof are deterministic fixtures.
- The real Candida candidate plateaued.
- LLM proposals are never execution authority.
