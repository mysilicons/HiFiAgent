# HiFi Agent v1.0.0

First stable V1 release of the constrained PacBio HiFi assembly Agent.

Highlights: deterministic Nextflow execution, typed QC artifacts, 14 versioned expert rules,
four-parameter hifiasm whitelist, budgeted controller, optional source-grounded DeepSeek
explanation, bounded multi-metric optimization, reproducible reports, 10 automated scenarios,
82.06% safety-critical coverage, and a retained public Candida albicans example.

Quick demo:

```bash
python -m pip install -e .
hifi-agent demo /tmp/hifi-agent-demo
```

Read `CHANGELOG.md` for limitations. Large biological data and external tool databases are not
included in the release.
